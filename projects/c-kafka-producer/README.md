# C Kafka Telemetry Producer

A low-level event producer written in C using librdkafka. It models industrial telemetry events and publishes keyed JSON messages to Kafka for downstream streaming/data-platform consumers.

**Technologies:** C · Linux · librdkafka · Apache Kafka · JSON · event streaming · Make

The case complements the Kafka/Terraform platform by showing a native producer rather than a Python-only client.
