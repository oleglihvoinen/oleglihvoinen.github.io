# Microsoft Fabric Enterprise Data Platform

Reference architecture for an enterprise medallion data platform on Microsoft Fabric.

**Technologies:** Microsoft Fabric · OneLake · Lakehouse · Data Factory · PySpark · Delta · SQL · Power BI · semantic models · data quality

Flow: Sources -> Data Factory -> Bronze -> PySpark Silver -> Gold -> Semantic Model -> Power BI / AI consumers.

The repository contains representative PySpark transformation and architecture documentation. It is a portfolio/reference design and does not claim a live Fabric deployment.
