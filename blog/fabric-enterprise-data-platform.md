# Microsoft Fabric Enterprise Data Platform

**Role focus:** Data Engineering · Lakehouse Architecture · Analytics Engineering

A reference enterprise data platform built around the **Microsoft Fabric medallion architecture**: source ingestion through Data Factory, OneLake/Lakehouse Bronze storage, PySpark/Delta transformations into Silver, governed Gold models, semantic modeling and Power BI/AI consumption.

**Technologies:** Microsoft Fabric · OneLake · Lakehouse · Data Factory · PySpark · Delta · SQL · Power BI · semantic models · data quality.
