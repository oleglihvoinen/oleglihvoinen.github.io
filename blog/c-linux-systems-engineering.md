# C & Linux Systems Engineering

Three portfolio/reference implementations connect low-level systems programming with the data-engineering stack.

## Linux System Metrics Agent
A lightweight C agent reads Linux kernel/system interfaces and emits structured host telemetry. It demonstrates **C, Linux, POSIX, /proc, filesystem statistics, systemd, JSON and observability**.

## C Kafka Telemetry Producer
A native **librdkafka** producer publishes keyed industrial telemetry events to Kafka, demonstrating C/Linux networking-oriented integration with an event-streaming data platform.

## Mini Database Storage Engine
A compact C storage engine demonstrates binary persistence, record lookup and database-internals concepts below higher-level SQL systems.

These cases are intentionally reference implementations rather than claims of production deployment.
